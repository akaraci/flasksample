IRIS MAKINE OGRENMESI WEB UYGULAMASI

1) Klasore gir:
   cd ml_web_app

2) Gerekli kutuphaneleri yukle:
   pip install -r requirements.txt

3) Uygulamayi baslat:
   python app.py

4) Tarayicidan ac:
   http://127.0.0.1:5000

Ornek deger:
Sepal Length: 5.1
Sepal Width: 3.5
Petal Length: 1.4
Petal Width: 0.2

Bu uygulama:
- scikit-learn Iris veri setini kullanir.
- Random Forest modeli egitir.
- Flask ile web sunucusu olusturur.
- HTML/CSS arayuzu sunar.
- Kullanici girdisini modele gonderir.
- Tahmin sonucunu web sayfasinda gosterir.
